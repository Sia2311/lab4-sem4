# Система управления инцидентами безопасности в образовательном учреждении

Веб-приложение предназначено для регистрации, контроля и обработки инцидентов безопасности в образовательном учреждении.

## Основной функционал

- регистрация и авторизация пользователей;
- двухфакторное подтверждение входа через email;
- разграничение ролей пользователей;
- создание и просмотр инцидентов;
- редактирование и закрытие инцидентов;
- интерактивная карта корпуса;
- выбор этажа и места происшествия на плане;
- автоматическое определение кабинета или зоны;
- отображение точек инцидентов на карте;
- админ-панель;
- управление пользователями;
- журнал действий администратора и пользователей.

## Роли пользователей

- `student` — может создавать инциденты и просматривать список;
- `teacher` — может создавать и просматривать инциденты;
- `security` — может редактировать и закрывать инциденты;
- `admin` — имеет полный доступ к системе.

Настройка окружения

В папке backend необходимо создать файл .env.

Пример:

PORT=4000
MONGO_URI=mongodb://127.0.0.1:27017/lab4_incidents
JWT_SECRET=your_secret_key

MAIL_HOST=smtp.gmail.com
MAIL_PORT=465
MAIL_SECURE=true
MAIL_USER=your_email@gmail.com
MAIL_PASSWORD=your_app_password

Файл .env не должен загружаться в GitHub.

Запуск backend
cd backend
npm install
npm run dev

Backend запускается по адресу:

http://localhost:4000
Запуск frontend

Во втором терминале:

cd frontend
npm install
npm start

Frontend запускается по адресу:

http://localhost:3000
Сборка frontend
cd frontend
npm run build
Деплой

Для запуска на сервере можно использовать PM2:

cd backend
npm install
pm2 start npm --name laba4 -- start
pm2 save
Назначение проекта

Проект разработан для демонстрации работы веб-системы мониторинга инцидентов безопасности в образовательном учреждении. Система позволяет централизованно хранить информацию о происшествиях, отслеживать их статус, назначать ответственных лиц и визуально отображать место возникновения инцидента на карте корпуса.
